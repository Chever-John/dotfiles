# BetterDisplay

BetterDisplay 是一款专业的 macOS 显示器管理软件，用于调节和优化多显示器环境下的显示参数。它提供了丰富的菜单定制选项和显示器控制功能，帮助用户获得更好的视觉体验。

## 功能详解

### 1. 菜单栏图标设置

#### 显示应用图标
- **功能**：在菜单栏中显示 BetterDisplay 的应用图标
- **作用**：提供快速访问应用功能的入口
- **使用场景**：当需要频繁调整显示器设置时，建议开启此选项便于快速访问
- **注意**：如果菜单图标被隐藏，可以通过重新启动应用来恢复显示

#### 附加菜单栏图标选项
- **功能**：提供更多菜单栏图标的自定义选项
- **作用**：进一步个性化菜单栏的显示方式

### 2. 菜单外观和行为

#### 显示滑块标签
- **功能**：在滑块控件上显示描述性标签
- **作用**：帮助用户快速识别各个滑块的功能
- **使用场景**：推荐开启，特别是初次使用或管理多个显示器时

#### 展开菜单项
- **功能**：在主应用菜单内展开可扩展的菜单项
- **作用**：减少点击层级，提供更直观的操作界面
- **使用场景**：适合需要经常调整多项设置的用户

#### 自动整理应用菜单
- **功能**：自动组织和优化菜单项的显示
- **作用**：防止菜单项过多时的视觉混乱，仅允许一个设备显示更多选项
- **使用场景**：在连接多个显示器时特别有用，避免菜单过于拥挤

#### 可分离应用菜单
- **功能**：允许将应用菜单从菜单栏区域拖出，独立显示
- **作用**：提供更灵活的操作方式，菜单可以保持持续可见
- **使用场景**：需要频繁调整设置或多任务操作时使用

#### 启用滑块的滚动/滑动手势
- **功能**：支持通过滚动或滑动手势操作滑块
- **作用**：提供更便捷的调整方式
- **使用场景**：默认禁用以避免意外的数值更改，建议谨慎开启

### 3. 自定义菜单选项

#### 菜单项可见性
- **功能**：自定义应用菜单中各项的显示/隐藏状态
- **作用**：个性化菜单内容，隐藏不需要的选项，突出常用功能
- **使用场景**：
  - 隐藏不常用的功能项
  - 为不同使用场景创建专用的菜单配置
  - 简化操作界面

### 4. 分辨率滑块设置

#### 显示和吸附滑块标记
- **功能**：在分辨率滑块上显示收藏和特殊分辨率的标记点
- **作用**：快速定位到预设的分辨率值，简化调整过程
- **使用场景**：
  - 经常在几个固定分辨率间切换
  - 需要精确设置特定分辨率值

#### 显示可缩放显示器的百分比
- **功能**：为支持缩放的显示器显示缩放百分比
- **作用**：提供更直观的缩放比例信息
- **使用场景**：
  - 使用 Retina 显示器或高 DPI 显示器
  - 需要精确控制界面元素大小

#### 使用放大倍数滑块
- **功能**：用放大倍数滑块替代传统的分辨率滑块
- **作用**：以 Linux 风格的方式反映 GUI 元素大小，影响分辨率快捷键功能
- **使用场景**：
  - 习惯 Linux 系统操作方式的用户
  - 更关心界面元素大小而非像素分辨率

#### 附加分辨率滑块设置
- **功能**：提供更多分辨率相关的高级设置选项

### 5. 显示模式菜单

- **功能**：提供显示模式相关的菜单选项和设置
- **作用**：管理不同的显示模式配置

## 使用建议

1. **初次使用**：建议开启"显示滑块标签"和"显示应用图标"
2. **多显示器环境**：启用"自动整理应用菜单"和"展开菜单项"
3. **频繁调整**：考虑使用"可分离应用菜单"功能
4. **精确控制**：开启"显示和吸附滑块标记"功能
5. **简化界面**：通过"菜单项可见性"隐藏不需要的功能

## 注意事项

- 滚动/滑动手势功能默认禁用，避免意外更改数值
- 放大倍数滑块会影响分辨率快捷键的行为
- 菜单图标隐藏后可通过重启应用恢复
